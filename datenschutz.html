What this site does not do

This site sets no cookies, uses no analytics or advertising services and loads no content from third-party servers. Fonts and scripts are served from this domain. There are no forms and no user accounts.

Hosting and server logs

The site is hosted by Hostinger International Ltd., 61 Lordou Vironos Street, 6023 Larnaca, Cyprus. When you open a page, the host processes technically necessary data in server logs: IP address, date and time, the file requested, the amount of data transferred, browser and operating system. This is needed to deliver the site and keep it secure (Art. 6 (1) (f) GDPR). How long the logs are kept is set by the host.

Links to GitHub

The site links to GitHub (GitHub, Inc., USA). Data is transferred to GitHub only when you click such a link; GitHub's own privacy statement then applies.

The app

The Mochi Squad app runs on your Mac and operates no server of its own. What it stores and what leaves your Mac is described in the project's README and SECURITY.md.
