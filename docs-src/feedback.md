## From the app

At the bottom of the icon bar:

- the ladybug, **Report a bug**,
- the light bulb, **Suggest a feature**.

Each opens a prepared form on GitHub in your browser. You fill it in and send it there. You need a GitHub account.

## On GitHub

- [Report a bug](https://github.com/fabianheimann5128/mochi-squad/issues/new?template=bug.md): what happened, what you expected, the steps to get there, and your Mochi Squad version, macOS version and Claude Code or Codex.
- [Suggest a feature](https://github.com/fabianheimann5128/mochi-squad/issues/new?template=feature.md): which problem it should solve, what the solution could look like, and what else you considered.

Your Mochi Squad version is shown under **What's new?** in the icon bar.

> [!WARNING]
> Issues are public. Do not paste credentials, tokens or private project content.

Security problems do not go into an issue. See [Report a vulnerability](security.md#report-a-vulnerability).
