---
title: Keyboard shortcuts
summary: The few shortcuts Mochi Squad has.
app: 0.2.1
---

| Shortcut | What it does |
|---|---|
| <kbd>⌘N</kbd> | New agent |
| <kbd>⌘↩</kbd> | Send the message (agent chat and team chat) |
| <kbd>↩</kbd> | Continue in setup and in the new-agent wizard; save in a dialog |
| <kbd>esc</kbd> | Cancel or close a dialog |
| <kbd>↩</kbd> in Mochi Memory | Remember the line you typed, or save a correction |
| <kbd>⌘Q</kbd> | Quit. With open sessions, you choose to keep them running in the background. |

## On this website

| Shortcut | What it does |
|---|---|
| <kbd>/</kbd> or <kbd>⌘K</kbd> | Search the docs |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>↩</kbd> | Pick a search result |
