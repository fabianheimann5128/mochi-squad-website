## What it is for

The coordinator is the first agent in every project. It is created for you and cannot be removed. Ask it things like:

- *What is the status of my projects?*
- *Which agents should I create for this project?*
- *What should I have done next?*

Through built-in tools it sees the state of all your projects, agents, sessions and routines. It can give a named agent a task and read saved chats. If no fitting agent exists for a task yet, it suggests that you create one.

## How you reach it

- In its own chat, at the top of the agent list.
- In the [team chat](team-chat.md): a message without a mention goes to the coordinator.
- From your phone, through [Telegram or WhatsApp](messengers.md).

Other agents cannot send the coordinator anything. Only you can.

## Change it

Open the coordinator's chat and click **Edit agent**. You can change its name, tasks, character, provider, model and rights like for any agent. Its job is always "Coordinator". The name of all coordinators is also set in [Settings](settings.md).

A new coordinator runs with Claude Code if that is installed, otherwise with Codex.

More in [The coordinator and its tools](coordinator.md).
