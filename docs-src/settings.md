Open Settings with the round button with your initial at the bottom of the icon bar. **Done** saves and closes.

| Setting | What it does |
|---|---|
| **Your name** | Your first name. Agents use it when they talk about you. |
| **Coordinator** | The name of your coordinators, in all projects. Default: Mochi. |
| **Language** | **English** or **Deutsch** for the interface. Agents answer in whatever language you write to them. |
| **Agent programs** | Claude Code and Codex: installed or not, signed in or not, with **Sign in** or **Guide**. See [Signing in](sign-in.md). |
| **More ChatGPT plans** | Extra ChatGPT plans for Codex agents. See [Several ChatGPT plans](chatgpt-plans.md). |
| **Messengers** | Telegram and WhatsApp, with **Set up** or **Manage**, and with more than one project **Team chat of**. See [Telegram and WhatsApp](messengers.md). |
| **This Mac** | **Keep this Mac awake while Mochi Squad is open**. See [Keeping the Mac awake](keep-awake.md). |
| **Keep in Dock** | Adds Mochi Squad to your Dock. Greyed out when it is already there. |
| **Show data in Finder** | Opens the app's data folder. See [Where your data is](data.md). |

## Settings elsewhere

Some things are set where you use them, not in this window:

- **Projects**: in the project menu at the top of the chat list. See [Projects](first-project.md).
- **Agents**: in **Edit agent**. See [Agents](agents.md).
- **Mochi Memory folder**: **Change folder …** in the memory window. See [Mochi Memory](memory.md#notes-on-your-mac-and-obsidian).
- **Skills**: in the Skills window. See [Skills](skills.md).
- **Connectors**: in the Connectors window. See [Connectors](connectors.md).
- **Updates**: **Check for Updates…** in the app menu. See [Updates](updates.md).
