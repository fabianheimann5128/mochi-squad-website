## Summarise and start fresh

1. Open the agent's chat and the **Context** tab in the right column.
2. Click **Summarise and start fresh**. It shows *Summarising …* for a moment.
3. A fresh chat starts with the summary. The agent confirms in one sentence and waits for you.

The old conversation stays readable under **More chats** in the chat list.

Once the context is 60 % full, the tab suggests it: *The context is getting full.*

## When it does not run

- While the agent is working. Tidy up once the answer is there.
- When the conversation is still very short.
- If the chat went on, or the agent's program or plan changed, while the summary was being written. Then nothing is replaced; try again when it is quiet.

## Good to know

- The summary covers the newest messages, up to 60,000 characters, and is at most about 250 words.
- It is written by a one-off run of the agent's own program, in an empty folder, with no tools.
- The summary is only as good as the model that wrote it. Check it if details matter, and keep important results in files.
