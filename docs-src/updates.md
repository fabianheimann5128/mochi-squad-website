## Automatic updates

The app looks for a new version on its own and asks you before it installs one. Updates come through [Sparkle](https://sparkle-project.org) from the project's latest GitHub release. A new version is installed only if it carries the project's signature.

## Check by hand

Choose **Mochi Squad › Check for Updates…** in the menu bar. The item is right below **About Mochi Squad**.

## What changed

Click the rocket (**What's new?**) in the icon bar. It shows the current version and its changes; **Earlier versions** unfolds the older ones. The full list is in the [changelog](changelog.md).

> [!NOTE]
> A copy you built from source never looks for updates. Pull and run `./setup.sh` again instead.
