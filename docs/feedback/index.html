    Help

    Report a bug or suggest a feature

    Tell us what is broken or what you are missing. The people who use Mochi Squad decide what gets built next.

    #From the app

    At the bottom of the icon bar:

    • the ladybug, Report a bug,
    • the light bulb, Suggest a feature.

    Each opens a prepared form on GitHub in your browser. You fill it in and send it there. You need a GitHub account.

    #On GitHub

    • Report a bug: what happened, what you expected, the steps to get there, and your Mochi Squad version, macOS version and Claude Code or Codex.
    • Suggest a feature: which problem it should solve, what the solution could look like, and what else you considered.

    Your Mochi Squad version is shown under What's new? in the icon bar.

    Careful

    Issues are public. Do not paste credentials, tokens or private project content.

    Security problems do not go into an issue. See Report a vulnerability.
