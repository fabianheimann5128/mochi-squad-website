    Getting started

    Your first agent

    Create an agent in six short questions. Each one gets a name, a job and a Mochi of its own.

    #Create the agent

    Click + at the top of the icon bar (or press ⌘N). In an empty project you can also click Create agent in the chat list.

    The wizard asks one question per page. Return moves on once the page is answered.

    1. What should your Mochi be called? You address it by this name in the team chat. A free name is suggested; Shuffle look gives the Mochi a new look.
    2. What is …'s job title? Type your own or take a suggestion: Developer, Researcher, Reviewer or Writer. A suggestion fills in fitting tasks and rights, which you can change on the next pages.
    3. What is …'s task? What this agent should do. Recurring tasks are set up later as routines.
    4. How should … behave? A few keywords on tone and way of working, for example "thorough and sceptical, dry humour".
    5. Which provider and model should … use? Choose Anthropic · Claude Code or OpenAI · Codex, then a model. The reasoning depth can stay on automatic. See Agents.
    6. What may … do? Choose Read only, Edit in project or Full access, and whether it may operate the computer. See Access levels.

    Click Create Mochi. The new agent appears in the chat list.

    #Give it a first task

    Open its chat. An empty chat offers three suggestions, such as Introduce yourself briefly and tell me what you can help with. Click one, or type your own message and press ⌘↩.

    The agent wakes up, starts its program and answers in the chat. See Chat and console.

    Tip

    Names must be unique within a project. In the team chat it would otherwise be unclear who is meant.
