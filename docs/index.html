    Mochi Squad docs

    Everything you can do with Mochi Squad, one task per page. Start with the first part if you are new; search with the / key if you know what you are looking for.

    Mochi Squad gives you a team of AI agents on your Mac. Each agent is Claude Code or Codex, running on the subscription you already have. You talk to them in a chat, they work in your project folders, and a coordinator keeps an eye on all of them.

    These pages describe version 0.2.1.
