    Keyboard shortcuts

    The few shortcuts Mochi Squad has.

    ShortcutWhat it does
    ⌘NNew agent
    ⌘↩Send the message (agent chat and team chat)
    ↩Continue in setup and in the new-agent wizard; save in a dialog
    escCancel or close a dialog
    ↩ in Mochi MemoryRemember the line you typed, or save a correction
    ⌘QQuit. With open sessions, you choose to keep them running in the background.
