    Reference

    Settings

    Every setting in one list, in the order the Settings window shows them.

    Open Settings with the round button with your initial at the bottom of the icon bar. Done saves and closes.

    SettingWhat it does
    Your nameYour first name. Agents use it when they talk about you.
    CoordinatorThe name of your coordinators, in all projects. Default: Mochi.
    LanguageEnglish or Deutsch for the interface. Agents answer in whatever language you write to them.
    Agent programsClaude Code and Codex: installed or not, signed in or not, with Sign in or Guide. See Signing in.
    More ChatGPT plansExtra ChatGPT plans for Codex agents. See Several ChatGPT plans.
    MessengersTelegram and WhatsApp, with Set up or Manage, and with more than one project Team chat of. See Telegram and WhatsApp.
    This MacKeep this Mac awake while Mochi Squad is open. See Keeping the Mac awake.
    Keep in DockAdds Mochi Squad to your Dock. Greyed out when it is already there.
    Show data in FinderOpens the app's data folder. See Where your data is.

    #Settings elsewhere

    Some things are set where you use them, not in this window:

    • Projects: in the project menu at the top of the chat list. See Projects.
    • Agents: in Edit agent. See Agents.
    • Mochi Memory folder: Change folder … in the memory window. See Mochi Memory.
    • Skills: in the Skills window. See Skills.
    • Connectors: in the Connectors window. See Connectors.
    • Updates: Check for Updates… in the app menu. See Updates.
